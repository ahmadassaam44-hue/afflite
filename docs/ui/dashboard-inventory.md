## الملفات المشتركة
- `dashboard/layout.php`: الهيدر، القائمة، التذييل، بطاقات المنتجات وKPI؛ بدأ العمل به.
- `dashboard/_payout.php`: نموذج وسجل سحب مشترك، ومعالج السحب بقي كما هو.
- `dashboard/buyer_lead_modal.php` + `render_easyorder_dialog_html()` في `config.php`: نافذة الطلب المشتركة.
- `assets/style.css` و`assets/ui.js`: Design System والسلوك المشترك.
- النسخة الاحتياطية موجودة في `assets/style.legacy.css` وأضيفت إليها تنسيقات الصفحات المستخرجة.

## المتوقع وغير الموجود
- لا يوجد `marketer_catalog.php` مستقل؛ الكتالوج هو `marketer.php?mtab=browse`.
- لا توجد صفحات مستقلة لمنشئ اللاندنج أو حسابي/العناوين أو محرّر المنتج الكامل.
- المتجر الحالي يدعم: العنوان، الوصف، واتساب، اللون، البيكسل، إضافة المنتجات وعمولتها.
- لا توجد endpoints/حقول حفظ للـslug، النشر/المسودة، اللوجو/الغلاف، أو headline/benefits. لم تُختلق إجراءات حفظ لها.
- محرّر الأدمن الموجود يدعم السعر، العنوان، رابط الصورة، الإخفاء والتثبيت فقط؛ لم تضف إجراءات للمتغيرات/SEO/وصف غير موجودة.

## تنبيه الأدوار
`ensure_user_affiliate()` يحوّل حساب المشتري المسجل إلى مسوّق في المنطق الحالي. لم يتغير ذلك؛ تنقل العميل يظهر في تدفقات الشراء، والتنقل الآخر بحسب الدور الفعلي الذي يقدمه النظام.
