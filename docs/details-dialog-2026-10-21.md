# ديالوج التفاصيل العام — 2026-10-21

## المشكلة

- تفاصيل طويلة كانت **بتتحشر في خلايا جداول صغيرة** (عنوان العميل، ملاحظات، أسباب، روابط، تفاصيل عمليات) — إما مبتورة بـ `mb_substr` (30–160 حرف) أو بتلخبط شكل الجدول.
- **أسباب الرفض/الإلغاء كانت مسجلة في البيانات ومش بتظهر في أي مكان**:
  - `cancel_reason` / `return_reason` للطلبات (إلغاء العميل/المسوق/الإدارة + طلبات الاسترجاع).
  - `payment_reject_reason` (سبب رفض إيصال الدفع) — بيتسجل من تبويب المدفوعات وماكانش بيظهر أبدًا.
  - رفض طلبات السحب كان **من غير سبب أصلًا** (مفيش خانة سبب).

## الحل

### 1) البنية الأساسية (تشتغل في كل الموقع)

| الملف | الإضافة |
|---|---|
| `ui-components.php` | `wf_details_btn($title,$rows,$label,$cls)` — زر صغير بـ JSON في `data-wf-details`. `wf_det_text($text,$len,…)` — معاينة قصيرة + زر النص الكامل. `wf_order_reasons_btns($o)` — أزرار أسباب الإلغاء/الاسترجاع/رفض الإيصال (تظهر فقط لو فيه سبب مسجل). `wf_order_details_rows($o)` — صفوف التفاصيل الكاملة للطلب (الفاضي بيتشال). |
| `assets/ui.js` | `wfDetails(title, rows)` — ديالوج عام بيتبني ديناميكيًا (نفس نمط مودال البحث بالصورة): عنوان + صفوف «اسم: قيمة» قابلة للتمرير، إغلاق بـ Esc أو ضغرة برا، وdelegation لكل `[data-wf-details]`. القيم بتترسم `textContent` ⇒ **آمنة ضد XSS**. القيم اللاتينية بتاخد `dir=ltr` تلقائيًا. |
| `assets/style.css` | `.wf-det-backdrop/.wf-det-card/.wf-det-row/...` + زر `.wf-det-danger` الأحمر للأسباب + `.wf-det-preview` للمعاينة. |

مفيش أي bump يدوي لإصدارات الأصول لازم — `wf_asset_v()` (PR السابق) بيغيّر النسخة تلقائيًا من
تاريخ تعديل الملف، فالجلسات القديمة هتشوف الديالوج الجديد من أول تحميل بعد النشر.

### 2) أماكن التطبيق

**الأدمن (`dashboard/admin.php`):**
- جدول الطلبات: زر «كل التفاصيل» (العنوان الكامل/المدينة/الملاحظات/اللون والمقاس/الهواتف) + أزرار أسباب الإلغاء/الاسترجاع/رفض الإيصال جنب الحالة + «كل الملاحظات» لكل سجل ملاحظات الإدارة (بالاسم والوقت) + «تفاصيل الخطأ» الكامل لفشل الإرسال للمصدر.
- أحدث الطلبات (نظرة عامة): زر تفاصيل كامل لكل طلب.
- طلبات توفير المنتجات: «التفاصيل الكاملة» لملاحظات الطلب.
- طلبات السحب: معاينة الملاحظات + زر، و**سبب رفض جديد** (خانة «سبب الرفض» في فورم الرفض ⇒ `reject_reason` بيتخزن ⇒ زر أحمر «سبب الرفض» في الجدول + بيوصل المسوق في الإشعار).
- مدفوعات السوشيال/الرقمي: «البيانات كاملة» للرابط/البيانات + **سبب رفض الإيصال بقى ظاهر** («سبب الرفض»).
- سجل النشاط (Audit): «التفاصيل الكاملة» بدل 90 حرف.
- أكواد نون الموقوفة/المرفوضة/المحذوفة: «السبب كامل» + وقت القرار ومن قرره.
- أخطاء الموقع: «الرسالة كاملة».

**المسوق:**
- `marketer.php` (طلباتي): زر «كل التفاصيل» للعنوان/الملاحظات + أزرار أسباب الإلغاء/الاسترجاع.
- `noon.php`: ملاحظة الإدارة على الكود بزر «الملاحظة كاملة»، والمنتج المرفوض بقى `alert danger` بارز + «السبب كامل».
- `_payout.php` (سجل السحب): «سبب الرفض» بالأحمر + «ملاحظاتي».

**العميل:**
- `orders.php`: أسباب الإلغاء/الاسترجاع بقت ظاهرة + «كل التفاصيل» (العنوان والملاحظات الكاملة).
- `dashboard/index.php`: «التعليق كامل» للتقييمات و«التفاصيل الكاملة» للعروض/الأخبار الطويلة.

**المنتجات اليدوية (`manual_products.php`):**
- زر «التفاصيل» لكل منتج: الوصف التفصيلي، الألوان، المقاسات، الخامة، الوزن، الأبعاد، SKU، الكمية، سعر الشحن، الأسئلة الشائعة، عدد الصور — بدل سطر واحد صغير.

### 3) الاختبارات

`tests/ui/manual-country-currency.cjs` — **376 assertion / 0 فشل** (كانت 363):
- قسم PHP جديد (16): بنية `data-wf-details`، عنوان/صفوف الـ JSON، القيمة الفاضية «—»، صفوف فاضية ⇒ مفيش زر، المعاينة والعلامة `…`، أزرار الأسباب (خطر/بدون)، العنوان الكامل في الصفوف، وXSS (وسوم واقتباسات بتتهرب).
- Wiring: الدوال الأربع في `ui-components.php`، `wfDetails` + delegation + `textContent` في `ui.js`، كلاسات `.wf-det-*` في `style.css`، والاستخدام في كل ملفات الداشبورد المعدلة، و`reject_reason` في مسار رفض السحب.
- php-parser بقى بيعمل parse لـ `dashboard/admin.php` و`noon.php` و`_payout.php` و`index.php` كمان.

### ملاحظات تشغيلية

- سبب رفض السحب **اختياري** — الرفض القديم شغال زي ما هو، والسبب الفاضي ما بيظهرش زر.
