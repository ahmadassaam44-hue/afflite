ملفات التفعيل التلقائي للكتالوج

محتويات هذا الأرشيف جاهزة للنسخ إلى مجلد المستودع hamama44/afflite مع الحفاظ على المسارات:
- updater/update_catalog.py
- updater/README.md
- .github/workflows/update-catalog.yml
- .htaccess (إصلاح حماية مجلد الرفع)

طريقة الرفع:
1) فك ضغط الأرشيف داخل نسخة محلية مستنسخة من مستودع afflite، ووافق على استبدال الملفات عند السؤال.
2) راجع التغييرات، ثم اعمل Commit وPush إلى الفرع main (باستخدام GitHub Desktop أو git).
3) لا ترفع ملف ZIP نفسه داخل المستودع؛ يجب أن تكون الملفات في المسارات المذكورة أعلاه.
4) لا تنسخ أي أسرار أو كلمات مرور إلى الملفات. بيانات المنصات محفوظة عبر GitHub Actions Secrets.
5) بعد الدفع، افتح Actions وشغّل "تحديث الكتالوج والأسعار" يدويًا مرة واحدة مع ترك خانة المصادر فارغة. بعد نجاح التشغيل، يستمر الجدول كل ست ساعات تلقائيًا.

ملاحظة: هذا الأرشيف لا يحتوي على secrets.php أو بيانات حسابات المستخدمين.
